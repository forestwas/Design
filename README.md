# Halı Saha Kadro

WhatsApp’a PNG olarak paylaşılabilen FIFA tarzı iki takımlı halı saha kadro kartı.

- Kişi sayısı: 6 / 7 / 8 (kaleci hariç)
- Kaleci opsiyonel (kiralanıyorsa kapalı)
- Skor girişi ve Pazartesi maç geçmişi (`localStorage`)
- Kartı PNG indir

## Çalıştırma

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```
